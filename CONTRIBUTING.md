# Contributing (Linux beta)

This repo is **isolated** from the official Windows product:
https://github.com/LasHSHS/SMK

- Prefer fixes that stay in this tree (packaging, platform paths, CI).
- Do not assume the maintainer can test your change on a Linux machine.
- Mark PRs clearly: **BETA / untested**.
- For core pipeline bugs that also affect Windows, open an issue on the Windows repo and link both ways.

Build: `./build_smk_unix.sh`
